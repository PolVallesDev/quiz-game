# 🎮 Quiz Game Web App

Juego de preguntas y respuestas para el navegador, desarrollado con HTML5, CSS3 y JavaScript vanilla. Proyecto gestionado con Kanban y control de versiones con Git/GitHub.

## 📖 Descripción

El jugador introduce su nombre, elige una de las dos categorías y responde preguntas con un límite de tiempo. Al final ve su puntuación y puede volver a jugar.

**Funcionalidades:**

- Entrada de nombre y selección de categoría.
- Preguntas generadas dinámicamente con validación en tiempo real.
- Temporizador de 15 s por pregunta con bloqueo automático.
- Pantalla de resultados con aciertos, fallos y opción de reiniciar.
- Diseño adaptativo con Flexbox y Media Queries.

## 🛠️ Tecnologías

- **HTML5:** estructura de las pantallas.
- **CSS3:** estilos y diseño responsive.
- **JavaScript (ES6+):** lógica del juego y manipulación del DOM.
- **Git y GitHub:** control de versiones y trabajo en equipo.
- **GitHub Projects:** tablero Kanban.

## 💻 Instalación local

Requisitos: Git y un navegador moderno.

```bash
git clone https://github.com/PolVallesDev/quiz-game.git
cd quiz-game
```

Abre `index.html` en el navegador, o usa la extensión **Live Server** de VS Code.

## 📋 Metodología Kanban

Las tareas se gestionan en un tablero de GitHub Projects con las columnas **To Do → In Progress → Review → Done**. Cada tarea es una tarjeta con un responsable asignado, y solo pasa a *Done* cuando funciona, ha sido revisada y está integrada en `main`. Cada funcionalidad se desarrolla en su propia rama y se integra mediante Pull Request.
